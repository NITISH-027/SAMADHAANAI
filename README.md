## 📌 Overview

SAMADHAANAI is an AI-powered compliance platform built to help MSMEs and Corporate Buyers manage payment compliance under **Section 43B(h)**.

The platform automates invoice analysis, compliance monitoring, legal reminders, and payment intelligence through AI, making regulatory compliance simple and efficient.

---

## ✨ Features

### 📄 AI Invoice Scanner
- Upload invoices
- Extract invoice details
- Validate payment information
- Compliance status detection

### 📊 Compliance Dashboard
- Compliance score
- Due invoices
- Risk analysis
- Payment insights

### 🤖 AI Compliance Copilot
- Ask compliance questions
- Explain Section 43B(h)
- Suggest next actions
- Legal guidance

### 📈 Analytics
- Payment trends
- Due amount tracking
- Compliance metrics
- Business insights

### 📑 PDF Report Generation
- Compliance reports
- Invoice summaries
- Downloadable PDFs

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/NITISH-027/SAMADHAANAI.git
```

```
cd SAMADHAANAI
```

---

## Backend Setup

```bash
cd backend
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run server

```bash
uvicorn app.main:app --reload
```

Backend

```
http://127.0.0.1:8000
```

API Docs

```
http://127.0.0.1:8000/docs
```

---

## Frontend Setup

```bash
cd frontend
```

Install packages

```bash
npm install
```

Run

```bash
npm run dev
```

Frontend

```
http://localhost:3000
```

# 🎯 Problem Statement

Delayed payments to MSMEs negatively impact cash flow and business operations. Manual compliance tracking under Section 43B(h) is time-consuming and prone to errors.

SAMADHAANAI simplifies this process through AI-powered automation, compliance monitoring, and actionable insights.
